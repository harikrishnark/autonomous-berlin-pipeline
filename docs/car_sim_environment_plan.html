City Environment Plan

A comprehensive breakdown of how you can connect to your remote VM using the native Windows app, the resources available for building an urban construction scene, and a step-by-step plan for proceeding with your car simulation project.

1. Connecting via the Omniverse Streaming Client

You asked if you can use the Isaac Windows app to connect to the remote VM. Yes, you can use the Omniverse Streaming Client on your local Windows PC to stream the high-fidelity UI from the headless Linux VM.

How it works:

  1. On the RunPod VM: You run Isaac Sim with the native streaming script (instead of the WebSocket script we used for the browser). 
    ./runheadless.native.sh
  2. Port Forwarding: The native streaming client uses a specific signaling port. You must forward TCP Port 49100 via your VS Code SSH tunnel.
⚠️ WARNING: Network Constraints

The native client heavily relies on a range of TCP/UDP ports (47995-48012 and 49000-49007) for the actual video stream. Because RunPod blocks UDP traffic by default, you may experience connection drops unless you map these ports explicitly in RunPod or use a VPN. If it fails, sticking to the WebSocket browser stream we set up earlier is the most reliable fallback.

  1. On your Windows PC: Open the Omniverse Streaming Client app. Enter 127.0.0.1 (since you forwarded the port) and click connect.

2. Building the Scene: Ready-Made Resources

To build a scene with roads, sidewalks, bicycle lanes, pedestrians, a construction site, and traffic cones, we don't have to start from scratch. Isaac Sim provides massive libraries of pre-built, physics-ready assets.

🏙️ Environments & Roads

  • City Scenes: Isaac Sim includes pre-built urban environments. In the Content Browser, navigate to Omniverse/Environments/City.
  • OpenDRIVE Importer: If you want procedurally generated, accurate road networks (with lanes, sidewalks, and intersections), Isaac Sim has a built-in OpenDRIVE importer extension that converts standard .xodr files into 3D USD roads.

🚧 Construction Site & Traffic Cones

  • SimReady Assets: NVIDIA provides "SimReady" assets which are pre-configured with accurate real-world scale, physics, and collisions.
  • Open the SimReady Explorer in the UI. Search for: Traffic Cone, Construction Barricade, Concrete Barrier, Pallets & Barrels.

🚶 Pedestrians & Dynamic Actors

  • Replicator Agent: Isaac Sim 6.0 includes the Replicator Agent (IRA) framework, which allows you to spawn animated pedestrians that walk along defined paths (like sidewalks and crosswalks) and react to the environment.
  • Character Assets: Found under Omniverse/Characters, providing rigged humans with walk cycles.

3. Implementation Plan: Creating the Urban Scene

Here is the step-by-step plan that was executed to build this environment.

Phase 1: Environment Foundation

  • Launch Isaac Sim and open an empty stage.
  • Import a base city block from the Environments catalog or use the OpenDRIVE importer to lay down the roads, sidewalks, and bicycle lanes.

Phase 2: The Construction Site

  • Open the SimReady Explorer.
  • Drag and drop traffic cones, barricades, and barriers onto the road to block off a lane.
  • Use the Replicator API to randomize the exact placement of the traffic cones (useful for training a perception model later).

Phase 3: Dynamic Elements (Pedestrians)

  • Import a rigged human character.
  • Use OmniGraph or the Replicator Agent tools to define a "Navigation Mesh" on the sidewalks.
  • Command the pedestrian to walk along the sidewalk and pause at the construction site.

Phase 4: The Vehicle

  • Import a pre-rigged vehicle (e.g., the standard ROS 2 Ackermann car model found in Assets/Robots).
  • Add RTX Lidar and RGB camera sensors to the front bumper.

4. Built-In Tutorials to Get Started

To get hands-on experience, Isaac Sim has excellent built-in tutorials accessible directly from the top menu bar under Help > Tutorials.

  • GUI & Environment: Help > Tutorials > GUI > Environment Setup (Teaches you how to drag, drop, and scale assets).
  • Replicator (Synthetic Data): Help > Tutorials > Replicator > Randomizing Objects (Teaches you how to scatter traffic cones programmatically).
  • ROS 2 Navigation (If using ROS): Help > Tutorials > ROS2 > ROS2 Ackermann Controller (Teaches you how to drive a car model).
