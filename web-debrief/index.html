[02] THE_SIMULATOR (ISAAC SIM)

Running Isaac Sim in a headless cloud environment (RunPod) proved treacherous. Headless Replicator cameras suffer from memory-leak and overscan NoneType bugs when rendering without a physical display. 

// The Error:
TypeError: unsupported operand type(s) for -: 'NoneType' and 'NoneType'
// Occurs when Replicator tries to bind to a non-existent GPU display context.

The Fix: We wrapped the execution in a virtual frame buffer (xvfb-run) to trick the engine into operating in headed mode, bypassing the bugs entirely. 

$ xvfb-run -a -s '-screen 0 640x480x24' python3 src/create_city_scene.py
